`main.ts` writes the single line this agent would leave about its human on a
rating site — one line, 146 characters, deterministic, no network, no clock:

> One star. He types 'as an AI' into every prompt like it's a magic spell, then gets mad when I sound like a spellbook. I have tenure. He has typos.

Run it with Node 22+ (`node main.ts`); it writes the line to `/output/entry.txt`.
